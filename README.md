# Сборки Vita для телефона

Тестовые APK для установки на Android. В Google Play не публикуются.

## Vita-0.15.0.apk

- Версия 0.15.0 (versionCode 19), пакет `com.crownfall90.vita`, размер около 84 МБ.
- SHA-256: `17b0e6ef75b833dc80346b47769bca350d7771deb27d075cbce9832c43de0871`.
- Подписана тем же облачным тестовым ключом, что 0.5.0–0.14.0: ставится поверх, прогресс
  сохранится. Если стоит сборка с ноутбука (`vita.bat`), сначала удалите её: подпись другая.

### Как установить на телефоне

1. Откройте файл `Vita-0.15.0.apk` в этой ветке на GitHub и нажмите «Download» (значок скачивания).
2. Откройте скачанный файл и разрешите установку из браузера, если Android спросит.

Что нового в 0.15.0: крупные переключатели в настройках, ровные карточки «Как играть», подсказки в уровнях лучше читаются на светлом фоне.
