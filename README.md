# Сборки Vita для телефона

Тестовые APK для установки на Android. В Google Play не публикуются.

## Vita-0.17.0.apk

- Версия 0.17.0 (versionCode 21), пакет `com.crownfall90.vita`, размер около 86 МБ.
- SHA-256: `cb33df0b4a6de9104e633cafbb41b8dafa7a0891338e2d72a12add5179d74d62`.
- Для почти всех телефонов (64-битных). Для старого 32-битного телефона, на который эта сборка
  не ставится, есть `Vita-0.17.0-old-phones-armv7.apk` (около 88 МБ, SHA-256 `37d12f13bf5e4d8a372f2bb043f8816ed4105b46da191a63f4924abaeaf99b4d`).
  Одним файлом обе версии весят больше 100 МБ, а GitHub такие файлы не принимает.
- Подписаны тем же облачным тестовым ключом, что 0.5.0–0.16.0: ставятся поверх, прогресс
  сохранится. Если стоит сборка с ноутбука (`vita.bat`), сначала удалите её: подпись другая.

### Как установить на телефоне

1. Откройте файл `Vita-0.17.0.apk` в этой ветке на GitHub и нажмите «Download» (значок скачивания).
2. Откройте скачанный файл и разрешите установку из браузера, если Android спросит.
