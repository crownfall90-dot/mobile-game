# Сборки Vita для телефона

Тестовые APK для установки на Android. В Google Play не публикуются.

## Vita-0.6.0.apk

- Версия 0.6.0 (versionCode 10), пакет `com.crownfall90.vita`, размер около 82 МБ.
- SHA-256: `48a6ad6a4325c385c8eeb57b61a76e7e76ef023e38e02c0f0d0a46c6101c158b`.
- Подписана тем же облачным тестовым ключом, что и 0.5.0 (APK Signature Scheme v2 и v3).
  Если стоит 0.5.0 из этой ветки — новая версия ставится поверх, прогресс сохранится.
  Если стоит сборка с ноутбука (`vita.bat`), сначала удалите её: подпись другая.

### Как установить на телефоне

1. Откройте файл `Vita-0.6.0.apk` в этой ветке на GitHub и нажмите «Download» (значок скачивания).
2. Откройте скачанный файл и разрешите установку из браузера, если Android спросит.
