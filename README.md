# Vita

Вертикальная мультяшная игра для Android на Godot 4.5.1: мама и маленькая дочь
ремонтируют квартиру, проходя головоломки внутри выбранных вещей. Сюжет подаётся
сценами визуальной новеллы.

**Акт 1: 19 ремонтов в четырёх локациях** — комната (4), кухня (5), санузел (5),
гостиная (5). Есть сохранения, покупки, обучение механикам и альбом сцен.
Сейчас идёт доработка первого акта, включая цельную расстановку интерьера.
Акт 2 не входит в текущую работу.

Структура акта задаётся `data/act1.json`, сценарий — `data/novel.json`, головоломки —
`levels/home_01.json` … `home_19.json`. Всё от прежних замыслов («Алхимическая башня»,
«Зелья и засовы», Мирра) удалено из проекта по решению владельца; оно осталось только в
истории репозитория.

## Запуск

Godot **4.5.1** без .NET: открыть `project.godot`, нажать F5.
На компьютере касания работают мышью. Базовый экран 720×1280, сцены интерьера
720×1560; адаптация равномерная, без растягивания объектов по одной оси.

## Проверки

```text
godot --headless --path . -- --home-selfcheck
godot --headless --path . -- --smoke
python tools/verify.py home_05 --quick --godot <путь-к-Godot>
```

Последняя команда проверяет выбранный уровень. Без `--quick` выполняется полный
набор G1–G7 с применимыми для механики проверками. Подробности и команды снимков —
в [архитектуре](docs/ARCHITECTURE.md#проверки-по-изменённому-поведению).

## Android

[Ветка тестовых APK](https://github.com/crownfall90-dot/mobile-game/tree/apk-builds).
Версию и подпись конкретной сборки сверять с её README и HANDOFF.
Идентификатор приложения: `com.crownfall90.vita`. Для обновления без удаления
сохранения нужен прежний ключ подписи. Успешная сборка не подтверждает проверку
на физическом телефоне. Публикация в Google Play не выполнялась.
