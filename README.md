# Сборки Vita для телефона

Тестовые APK для установки на Android. В Google Play не публикуются.

## Vita-0.5.0.apk

- Версия 0.5.0 (versionCode 9), пакет `com.crownfall90.vita`.
- SHA-256: `16070cb0f922bde8f3de169be96139ea7ddb03ac3aa8e793d59c3da2385142ae`.
- Подписана облачным тестовым ключом (APK Signature Scheme v2 и v3), а не ключом с ноутбука.
  Поэтому перед установкой удалите старую Vita: Android не обновит приложение с другой подписью.
  Прогресс начнётся заново.

### Как установить на телефоне

1. Удалите старую Vita: долгое нажатие на иконку → «Удалить».
2. Откройте файл `Vita-0.5.0.apk` в этой ветке на GitHub и нажмите «Download» (значок скачивания).
3. Откройте скачанный файл и разрешите установку из браузера, если Android спросит.

Что нового: квартира целиком видна на экранах от 16:9 до 21:9, на планшетах и раскладушках;
на кухне мама у плиты, дочка за столом; головоломки идут внутри вещей и без семьи
(окно, раковина, плита); фоны головоломок от художника; исправлена ошибка открытия квартиры.
