# Сборки Vita для телефона

Тестовые APK для установки на Android. В Google Play не публикуются.

## Vita-0.7.0.apk

- Версия 0.7.0 (versionCode 11), пакет `com.crownfall90.vita`, размер около 82 МБ.
- SHA-256: `3ade2fbf001f13143d53b7da3df13ae19a070c44c532777e0336bd0950554a24`.
- Подписана тем же облачным тестовым ключом, что 0.5.0 и 0.6.0: ставится поверх, прогресс
  сохранится. Если стоит сборка с ноутбука (`vita.bat`), сначала удалите её: подпись другая.

### Как установить на телефоне

1. Откройте файл `Vita-0.7.0.apk` в этой ветке на GitHub и нажмите «Download» (значок скачивания).
2. Откройте скачанный файл и разрешите установку из браузера, если Android спросит.

Что нового: сюжет в стиле визуальной новеллы — пролог при первом запуске (ночь, письмо
прабабушки, знакомство с Хмурью), сценка и кусочек фото прабабушки после каждой комнаты, финал
главы; альбом (кнопка-книжка) с фото и повтором сценок; Хмурь — серое облачко под потолком,
съёживается с каждым ремонтом, в конце становится другом; в паузе уровня — «Начать заново»;
картина из магазина висит на стене, а не на двери; ровный верх фонов в головоломках.
