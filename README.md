# Сборки Vita для телефона

Тестовые APK для установки на Android. В Google Play не публикуются.

## Vita-0.8.0.apk

- Версия 0.8.0 (versionCode 12), пакет `com.crownfall90.vita`, размер около 82 МБ.
- SHA-256: `39cb79c3c9e326840da7d2f8ccf9476c48059fa739be0d927ea212b30f932c5f`.
- Подписана тем же облачным тестовым ключом, что 0.5.0–0.7.0: ставится поверх, прогресс
  сохранится. Если стоит сборка с ноутбука (`vita.bat`), сначала удалите её: подпись другая.

### Как установить на телефоне

1. Откройте файл `Vita-0.8.0.apk` в этой ветке на GitHub и нажмите «Download» (значок скачивания).
2. Откройте скачанный файл и разрешите установку из браузера, если Android спросит.
