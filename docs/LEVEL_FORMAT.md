# Формат уровня (версия 2)

Уровень — JSON-файл `levels/<id>.json`. Имя файла и есть id уровня (`f1_05.json` → `f1_05`).
Все координаты — в пикселях поля 720×1280 (портрет), ось Y вниз.
Прямоугольник записывается как `[x, y, ширина, высота]`, точка — `[x, y]`.

Файлы формата 1 (без `"format": 2`, с `title` строкой) по-прежнему загружаются.

## Каталог: `levels/index.json`

```json
{"format": 2,
 "floors": [
  {"id": "storeroom", "n": 1, "title": {"ru": "Кладовая", "en": "The Storeroom"}, "theme": "storeroom",
   "levels": ["f1_01", "f1_02", "f1_03", "f1_04", "f1_05", "f1_06"]}],
 "teaser": {"title": {"ru": "Ледник", "en": "The Frost Cellar"}, "text": {"ru": "…", "en": "…"}}}
```

- Порядок этажей и уровней в индексе — порядок прохождения (`Game.next_level_after`).
- Подпись уровня — «этаж-позиция» из полного списка этажа: `f2_03` → «2-3».
- Уровень из индекса без файла пропускается с одним предупреждением на запуск:
  игра работает с теми уровнями, что уже есть.
- Индекс правят только F0 и интегратор. Уровень вне индекса открывается по id
  (`--level=<id>`) или по пути (`--file=res://levels/test/t_x.json`) для проверки.
- `levels/solutions/<id>.json` — список проверенных выигрышных порядков
  (`[["lava","water","gold","floor"], …]`) от `tools/verify.py`. Нет файла — подсказки
  берут `solution`.

## Пример

```json
{
  "format": 2,
  "id": "f1_05",
  "floor": 1,
  "title": { "ru": "Горячий приём", "en": "Hot Welcome" },
  "hint": { "ru": "Не спеши: порядок засовов важен", "en": "Take your time: pin order matters" },
  "tutorial": "",
  "intro": "",
  "hard": true,
  "tower": { "rect": [130, 200, 460, 1010] },
  "walls": [ { "poly": [[100, 180], [130, 180], [130, 1240], [100, 1240]] } ],
  "pins": [ { "id": "lava", "from": [68, 586], "to": [360, 586] } ],
  "fills": [ { "kind": "lava", "rect": [136, 404, 212, 168], "count": 34 } ],
  "enemies": [ { "kind": "slime", "pos": [245, 770] } ],
  "hero": { "pos": [360, 1210], "zone": [130, 960, 460, 250] },
  "goal": { "gold": 0.7 },
  "solution": ["lava", "water", "gold", "floor"],
  "fails": [["water", "lava", "gold", "floor"], ["floor", "lava", "water", "gold"]],
  "verify": { "max_win_share": 0.17 }
}
```

## Поля

| Поле | Что это |
|---|---|
| `format` | `2`. Нет поля — формат 1 |
| `id` | совпадает с именем файла; от него зависит «случайный» вид камней и цвет самоцветов |
| `floor` | номер этажа (1–3); для уровней из индекса берётся из индекса |
| `title`, `hint` | строка (считается русской) или `{"ru": …, "en": …}`. `hint` — надпись над героиней до первого засова, `""` — без неё |
| `tutorial` | `""`, `"hand"` — рука показывает на `solution[0]`, `"hint"` — урок подсказки (делает поток Game UX) |
| `intro` | id карточки нового элемента перед первой попыткой (`water_lava`, `slime`, `acid`, …), `""` — без карточки |
| `hard` | `true` — «сложный» уровень (красная метка, двойной бонус) |
| `tower.rect` | внутренняя часть башни: задник с кладкой и зубцы сверху |
| `walls[].poly` | статичные стены: любые выпуклые или вогнутые многоугольники (по часовой или против) |
| `pins[]` | засовы. `from` — центр кольца-ручки, `to` — кончик. Засов выезжает в сторону ручки. Ручку ставь снаружи башни, кончик — в стену или перегородку |
| `fills[]` | чем заполнить камеру: `kind`, `rect`, `count`. Тела укладываются рядами снизу вверх внутри `rect` |
| `enemies[]` | враги: `kind` (`slime`), `pos` — центр (радиус 30) |
| `hero.pos` | точка между ступнями Мирры |
| `hero.zone` | зона героини: сокровища здесь собираются, лава, кислота или живой враг здесь — поражение |
| `goal` | цель, см. ниже |
| `solution` | выигрышный порядок засовов (автотест, подсказки, «рука») |
| `fails` | порядки, которые обязаны проигрывать (проверка G4). У уровней с 2+ засовами — хотя бы один |
| `verify.max_win_share` | допустимая доля выигрышных порядков из всех (1-й уровень этажа 0.50, 2–4-й 0.34, 5-й 0.17, 6-й 0.25) |
| `verify.daily` | `false` — уровень не годится для «Зелья дня» (по умолчанию `true`) |

### Вещества (`fills[].kind`)

| kind | Радиус | Поведение |
|---|---|---|
| `water` | 9 | течёт; с лавой даёт камень (и исчезает); разбавляет кислоту |
| `lava` | 9 | вязкая, светится; убивает слизней и Мирру; от воды застывает волной по всей луже |
| `acid` | 9 | течёт; убивает; растворяет камень (оба исчезают); от воды становится водой |
| `gold` | 11 | монета: 1 сокровище, платит 1 монету |
| `gem` | 11 | самоцвет: физика как у монеты, 1 сокровище, платит 5 монет |
| `stone` | 9 | безопасный камень; растворяется кислотой |

Жидкости (`water`, `lava`, `acid`) проходят сквозь сито (слой `LAYER_SIEVE`), всё остальное
на нём лежит. Само сито и остальные новые элементы добавляет поток механик (см. конец файла).

### Цель и звёзды

- `{"gold": 0.7}` — доля: нужно `ceil(0.7 × сокровищ)`, 3 звезды — от 95% сокровищ.
- `{"pieces": 16, "three_star": 26}` — число: нужно 16, 3 звезды — от 26
  (для уровней, где сокровища появляются по ходу, например из круга превращения).
- 2 звезды — от середины между целью и порогом 3 звёзд, 1 звезда — цель выполнена.
- На уровне без сокровищ победа всегда даёт 3 звезды.
- Сокровища — монеты и самоцветы. Ингредиент (`relic`) в счёт не идёт.

## Правила

- **Победа**: цель выполнена, живых врагов нет и **0,8 с не пришло ни одного сокровища**
  (но не позже 3 с после выполнения цели) — докатывающиеся монеты успевают попасть в счёт.
  До первого вытащенного засова уровень не решается.
- **Поражение**: лава, кислота или живой враг в зоне героини (проверяется до самой победы),
  либо все засовы вытащены, а победы нет 5 секунд (`stuck`).
- В момент победы или поражения счёт замирает: `Level.result()` возвращает тот снимок,
  из которого посчитаны звёзды: `{won, stars, pieces, pieces_total, needed, coins_pieces, gems, relic, reason}`.
- Причины поражения: `lava`, `acid`, `enemy`, `stuck`.
- **«Золотая лихорадка»** (`Game.load_level(id, {"golden": true})`): всё `gold` становится `gem`.
  Физика та же, поэтому решение остаётся верным.

## Реакции и события

Реакции — таблица `Level._init()`: пара веществ → обработчик, порядок в паре не важен.
Кого чем можно убить — таблица `Level.VULNERABLE` (`slime`: лава, кислота).
Уровень не играет звуки и не трогает сохранение: он шлёт сигналы, а экран и эффекты отвечают.

| `Level.reaction` id | info | Когда |
|---|---|---|
| `steam` | `{}` | вода коснулась лавы |
| `stone` | `{n}` | лава застыла; `n` — номер камня в текущей волне |
| `wave_end` | `{n}` | волна застывания кончилась; `n` — камней в ней |
| `slime_pop` | `{enemy, killer}` | враг погиб (`slime`, `lava`/`acid`) |
| `acid_stone` | `{}` | кислота растворила камень |
| `dilute` | `{}` | вода разбавила кислоту |
| `noble_gold` | `{}` | кислота коснулась золота (ничего не случилось); раз за уровень |

`Level.collected(kind, pos)`: `coin`, `gem`, `relic`. Засовы — сигнал `pin_pulled`.

## Проверка уровня

Флаги пишутся после `--`; полный список — в начале `scripts/dev/dev_runner.gd`.

```
godot --headless --path . --fixed-fps 60 -- --level=f1_05 --autoplay --json
godot --headless --path . --fixed-fps 60 -- --level=f1_05 --pins=water,lava,gold,floor
godot --headless --path . --fixed-fps 60 -- --level=f1_05 --autoplay --interval=settle --jitter=1
godot --headless --path . --fixed-fps 60 -- --file=res://levels/test/t_x.json --all-at-once
godot --path . -- --level=f1_05 --autoplay --shot=/tmp/win.png@12
GODOT=godot tools/test_levels.sh
```

Итог — строка `RESULT: WON stars=3 gold=22/22` или `RESULT: LOST reason=enemy`, с `--json` ещё
`RESULT_JSON {"level":"f1_05","order":[…],"won":true,"reason":"","stars":3,"pieces":22,"total":22,"relic":false,"t":7.3}`.
Один запуск занимает около секунды.

Уровень готов, когда решение выигрывает на 3 звезды с `--jitter=0/1/2`, с `--interval=1.5`, `0.8`
и `settle`, каждый порядок из `fails` проигрывает с `--jitter=0` и `1`, а `--all-at-once`
не выигрывает (для уровней с 3+ засовами).

## Советы по дизайну уровней

- Капля — круг радиусом 9, монета и самоцвет — 11. Делай камеры хотя бы 60 px шириной.
- Толщина засова 14 px: ставь `fills.rect` так, чтобы низ был на 5–8 px выше засова.
- Полы наклоняй от 15° к выходу, чтобы капли не зависали на ровных полках.
- Сначала придумай неправильный порядок, который проигрывает, и геометрию под него,
  потом проверь его флагом `--pins`.
- Цель-доля 0.6–0.7, никогда не 1.0. 3 звезды закладывай, только если решение стабильно
  собирает 95%.
