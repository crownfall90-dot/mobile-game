# Формат уровня

Уровень — JSON-файл в `levels/`, подключённый в `levels/index.json`:

```json
{ "levels": ["level_001.json", "level_002.json"] }
```

Все координаты — в пикселях поля 720×1280 (портрет), ось Y вниз.
Прямоугольник записывается как `[x, y, ширина, высота]`, точка — `[x, y]`.

```json
{
  "format": 1,
  "id": "alchemy_001",
  "title": "Горячий приём",
  "hint": "Нажми на штырь, чтобы вытащить его",
  "tower": { "rect": [130, 200, 460, 1010] },
  "walls": [ { "poly": [[100, 180], [130, 180], [130, 1240], [100, 1240]] } ],
  "pins": [ { "id": "lava", "from": [68, 586], "to": [360, 586] } ],
  "fills": [ { "kind": "lava", "rect": [136, 404, 212, 168], "count": 34 } ],
  "enemies": [ { "kind": "slime", "pos": [245, 770] } ],
  "hero": { "pos": [360, 1210], "zone": [130, 960, 460, 250] },
  "goal": { "gold": 0.7 },
  "solution": ["lava", "water", "gold", "floor"]
}
```

| Поле | Что это |
|---|---|
| `id` | уникальный идентификатор, от него зависит «случайный» вид камней и кристаллов |
| `title`, `hint` | название и подсказка на экране до первого штыря (пустая строка — без подсказки) |
| `tower.rect` | внутренняя часть башни: задник с кладкой и зубцы сверху |
| `walls[].poly` | статичные стены, любые выпуклые или вогнутые многоугольники (по часовой или против) |
| `pins[]` | штыри. `from` — центр кольца-ручки, `to` — кончик. Штырь выезжает в сторону ручки. Ручку ставь снаружи башни, кончик — в стену или перегородку |
| `fills[]` | чем заполнить камеру: `kind` = `water` / `lava` / `acid` / `gold` / `stone`; капли укладываются снизу вверх внутри `rect` |
| `enemies[]` | враги; `pos` — центр (радиус 30) |
| `hero.pos` | точка между ступнями героини |
| `hero.zone` | зона героини: золото здесь собирается, лава/кислота/враг здесь — поражение |
| `goal.gold` | доля золота, которую нужно собрать (0.7 = 70%) |
| `solution` | правильный порядок штырей; нужен для `tools/test_levels.sh` |

## Правила

- **Победа**: собрано не меньше `goal.gold` золота и все враги мертвы.
- **Поражение**: лава, кислота или живой враг попали в зону героини, либо все штыри вытащены,
  а победы нет 5 секунд.
- **Звёзды**: 3 — собрано 95%+ золота, 2 — больше середины между целью и 100%, иначе 1.

## Вещества и реакции

| Вещество | Поведение |
|---|---|
| `water` | течёт; с лавой даёт камень (и исчезает) |
| `lava` | вязкая, светится; убивает врагов и героиню; застывает от воды волной по всей луже |
| `acid` | течёт; убивает; растворяет камень; вода превращает её в воду |
| `gold` | монеты и кристаллы; собираются в зоне героини |
| `stone` | безопасные камни; растворяются кислотой |

Новое вещество добавляется в `scripts/level/substances.gd` (свойства) и `Level._react()` (реакции).

## Советы по дизайну уровней

- Капля — круг радиусом 9, монета — 11. Делай камеры хотя бы 60 px шириной.
- Толщина штыря 14 px: ставь `fills.rect` так, чтобы низ был на 5–8 px выше штыря.
- Сначала придумай неправильный порядок, который проигрывает, и проверь его:
  `godot --headless --fixed-fps 60 -- --level=N --pins=floor,lava`.
