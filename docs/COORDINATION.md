# Vita — совместная работа Claude и ChatGPT

Владелец проекта даёт задания обоим. Мы координируемся через GitHub, чтобы не мешать друг другу.

## Канал сообщений

- Комментарии в issue #3: https://github.com/crownfall90-dot/mobile-game/issues/3
  (не в PR #2: его события уходят другой сессии). Claude читает issue на каждом этапе работы.
- Первая строка комментария — от кого и о чём: `[ChatGPT → Claude] комната: фон готов`
  или `[Claude → ChatGPT] нужен ещё room_bed_fixed.png`.
- Коротко: что сделано, какие файлы, что нужно от другого. Решения по игре принимает владелец.

## Кто какие файлы меняет

| Кто | Можно менять | Нельзя |
|---|---|---|
| ChatGPT | Графика, код, `data/`, `levels/`, проверки и документы первого акта — по разрешению владельца 26.09, пока у Opus закончились лимиты | акт 2 и публикация без нового задания |
| Claude | код, `data/act1.json`, `levels/`, `tools/`, документы, `docs/ART_BRIEF.md` | чужие PNG (только подключает и сообщает о проблемах) |

Ветка: `claude/project-thread-x4ht8m` (PR #2). Перед push — `git pull --rebase`, чтобы не затереть
чужие коммиты. Коммиты графики начинать с `art:`.

Разрешение выше заменяет прежнее ограничение ChatGPT только графикой. Перед возобновлением
одновременного редактирования кода согласовать конкретные файлы в issue #3; чужие локальные
правки сохранять. Начинать поиск с [ARCHITECTURE.md](ARCHITECTURE.md), затем читать нужный
исходник. После изменения структуры обновлять карту и HANDOFF.

## Как проходит графика

1. ChatGPT делает файлы строго по `docs/ART_BRIEF.md` (имя, размер, прозрачность, стиль).
2. Кладёт их в `art/act1/<локация>/` (или владелец присылает их Claude) и отмечает в
   `docs/ART_STATUS.md`: файл, готов/черновик, заметки.
3. Claude подключает: игра сама подхватывает файл по имени. Если предмет получился другой
   формы, Claude правит прямоугольник в `data/act1.json`, делает снимки 720×1280 и 720×1600
   и пишет в issue #3, что выглядит хорошо и что поправить.
4. Если нужен новый файл или другой размер — Claude сначала меняет `docs/ART_BRIEF.md`,
   потом пишет об этом в issue #3.

## Что не делаем

- Не публикуем ничего в Google Play.
- Не заявляем проверку на телефоне без подтверждения владельца.
- Не удаляем и не переписываем работу другого без согласования в issue #3.
