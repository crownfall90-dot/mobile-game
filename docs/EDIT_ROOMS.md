# Как расставлять мебель в комнатах мышкой (Godot)

1. Открой проект в Godot 4.5. Плагин «Vita: расстановка комнат» включён (Проект → Настройки
   проекта → Плагины).
2. Открой сцену комнаты: `scenes/locations/room.tscn` (kitchen, bath, living — остальные).
3. Каждая вещь — отдельная картинка (Sprite2D). Фон заблокирован, розовая рамка «Видно на
   телефоне» — что видно на любом экране.
   - двигать — тянуть мышкой;
   - размер — ручки по углам (с Shift — с сохранением пропорций) или Scale в инспекторе;
   - отразить — галочка Flip H;
   - повернуть — Rotation (поворот наклоняет картинку, другой бок не покажет — нужен свой рисунок);
   - кто впереди — Z Index (больше — ближе к зрителю; до 199 — за героями первой комнаты,
     200 и больше — перед ними).
4. Ctrl+S — расстановка сохраняется в `data/layout/<комната>.json`, игра ставит всё так же;
   круглые кнопки и нажатия переезжают вместе с вещью.
5. Отменить свою расстановку — удалить `data/layout/<комната>.json`.

Сцены пересобираются из данных командой `python3 tools/make_location_scenes.py` (учитывает уже
сохранённую расстановку).
