# Архитектура «Зелья и засовы»

Godot 4.5.1, GDScript со статической типизацией, рендер GL Compatibility, портрет 720×1280.
Всё процедурное: `_draw`, шейдеры, SVG в коде, синтезированный звук. Полный дизайн: [DESIGN.md](DESIGN.md);
кто владеет каким файлом — §18.1, публичные API — §18.3, форматы данных — §18.4.

## Запуск

`scenes/main.tscn` — пустой `Node` со `scripts/boot.gd`, который отложенно зовёт `Router.boot()`.
Дальше:

- есть dev-флаги (что-то после `--`) → `DevRunner` (`scripts/dev/dev_runner.gd`) получает `Game.dev`;
- иначе → экран `loading`, он готовит данные и открывает хаб (или первый уровень при первом запуске).

Если скрипта экрана ещё нет, Router открывает `game` с `{id: Profile.current_level_id()}`:
приложение всегда загружается во что-то играбельное.

## Автозагрузки (именно в этом порядке)

| Имя | Файл | Задача |
|---|---|---|
| `Loc` | `scripts/core/loc.gd` | Строки RU/EN из `data/strings/*.json`, выбор языка |
| `Profile` | `scripts/core/profile.gd` | Всё состояние игрока и сохранение. Никаких правил |
| `Game` | `scripts/core/game.gd` | Каталог уровней (`levels/index.json`), разбор dev-флагов в `Game.dev` |
| `Economy` | `scripts/core/economy.gd` | Правила наград, цен, сундуков, календаря; меняет `Profile` |
| `Sfx` | `scripts/audio/sfx.gd` | Синтез звуков, музыка, вибрация. Молчит в headless |
| `Monetization` | `scripts/core/monetization.gd` | Заглушки рекламы и покупок: всё «недоступно» (§14) |
| `Router` | `scripts/core/router.gd` | Экраны, попапы, тосты, «назад», сворачивание |

Autoload-узлы создаются все сразу, а `_ready` у них идёт по порядку, поэтому в `_ready`
нельзя рассчитывать, что следующие по списку уже загрузились (Loc подписывается на Profile отложенно).

## Экраны

Экран — любой `Node` (обычно полноэкранный `Control`) в `scripts/screens/`:

- `open(args: Dictionary)` — обязательно; Router зовёт его сразу после добавления в дерево;
- `on_back() -> bool` — по желанию; `true` значит «обработал сам»;
- `on_app_pause()` — по желанию; приложение свернули или оно потеряло фокус (один раз до возврата);
- `on_resume()` — по желанию; экран снова сверху после `Router.back()`.

Реестр `Router.SCREENS`: `loading`, `hub`, `map`, `game`, `wardrobe`, `grimoire`
(файлы `<имя>_screen.gd`).

- `Router.go(name, args)` заменяет весь стек, `Router.push(name, args)` кладёт экран сверху,
  `Router.back()` возвращает предыдущий. Переход — затемнение 0,25 с цветом `#120c24`.
- Экран под `push` снимается с дерева (не рисуется, физика стоит) и возвращается на `back()`.
- Экраны живут под узлом с `PROCESS_MODE_PAUSABLE`; попапы, тосты и сам Router работают и на паузе.
- При смене экрана попапы старого экрана закрываются, а `get_tree().paused` сбрасывается в `false`.
  Попап, открытый сразу после `go()`, остаётся.
- Сигнал `Router.screen_changed(name)`.

## Попапы

Попап наследует `UiPopup` (`scripts/ui/popup.gd`): полноэкранный `Control` с `signal closed(result)`,
`open(args)`, `close(result = null)` (анимация, `closed`, освобождение) и `on_back()` (закрывает).

`Router.popup(name, args)` создаёт его на слое 50 и возвращает узел, либо `null`, если скрипта
ещё нет (вызывающий обязан это проверить). Реестр `Router.POPUPS`: `pause`, `result`, `chest`,
`settings`, `confirm`, `intro_card`, `story_card`, `floor_complete`, `daily`. Для другого имени
Router ищет `scripts/popups/<имя>_popup.gd`, `<имя>_card.gd`, `<имя>.gd`.

Попап подтверждения: `open({title, text, ok, cancel})`, закрывается с `true` (да) или `false`.

## Кнопка «назад» и жизненный цикл

`quit_on_go_back=false`. Системная «назад» (и Esc на компьютере):

1. верхний попап → его `on_back()`;
2. иначе текущий экран → `on_back()`; если вернул `true`, всё;
3. иначе `Router.back()`: предыдущий экран; с последнего — в хаб; в хабе — «Выйти?» через `confirm`
   (без этого попапа — сразу выход с сохранением).

Сворачивание (`NOTIFICATION_APPLICATION_PAUSED`, потеря фокуса) передаётся экрану в `on_app_pause()`;
в dev-запусках — нет. Profile сохраняется немедленно при сворачивании и выходе.

## Тосты

`Router.toast(text, icon := &"")` — «пилюля» сверху по центру на 2 с, слой 90; несколько встают
в очередь. Иконка берётся из `Icons.tex()`, если `scripts/ui/icons.gd` уже есть.

## Сохранение (save v2)

`user://save.json`, формат — DESIGN §18.4. Запись атомарная: `save.tmp` → прошлый файл копируется
в `save.bak` → `save.tmp` переименовывается в `save.json`. Если `save.json` не читается, берётся
`save.bak` (так же, если в файле нет поля `v`). Значение не того типа (`null`, строка вместо числа)
при загрузке заменяется значением по умолчанию. Старый `user://progress.cfg` (версия 0.1)
переносится один раз: уровень 0 стал `f1_05`.

- Любое изменение зовёт `Profile.save()`: запись через 0,5 с, несколько изменений — одна запись.
  `Profile.flush()` пишет сразу.
- `Profile.volatile = true` — диск не трогается вообще. Включается само при любых dev-флагах.
- Economy может менять поля `Profile.data` (`streak`, `chest`, `daily`, `last_open`, `stats`)
  напрямую и затем звать `Profile.mark_changed(key)`.
- Открытие уровней: первый в `Game.level_ids()` открыт всегда, любой другой — когда пройден
  предыдущий (пропуск тоже считается). `current_level_id()` — первый открытый непройденный,
  иначе последний. Переигровка старого уровня прогресс не откатывает.
- После победы GameScreen вливает итог `Profile.record_result()` (`first_clear`, `new_stars`) в
  результат уровня и передаёт его в `Economy.level_reward()`; Economy берёт эти поля оттуда,
  а `Profile.last_record` — только запасной путь, если их в результате нет.

## Строки

Каждый модуль держит свой файл `data/strings/<модуль>.json` — плоский объект:

```json
{"common.play": {"ru": "Играть", "en": "Play"}, "common.level": {"ru": "Уровень {0}", "en": "Level {0}"}}
```

Loc склеивает все файлы при старте (по алфавиту; повтор ключа — предупреждение).
`Loc.t("common.level", ["2-3"])` подставляет `{0}`, `{1}`…; нет ключа — вернёт сам ключ и
один раз предупредит. `Loc.pick(v)` принимает строку или `{ru, en}` (так в уровнях заданы
`title` и `hint`). Язык: настройка `lang` = `auto` | `ru` | `en`; «Авто» даёт русский для
системных `ru`, `uk`, `be`, `kk`, иначе английский. `Loc.set_lang()` сохраняет и шлёт `lang_changed`.

Префиксы: `app.`, `common.`, `lose.` — core; `ui.` — Shell UI; `game.` — Game UX; `meta.` — Meta;
`store.` — Art/Store. Название игры в интерфейсе — только ключ `app.title`.

## Dev-флаги

Всё после `--` в командной строке; подробности — в шапке `scripts/dev/dev_runner.gd`.

| Флаг | Смысл |
|---|---|
| `--level=<id или номер>`, `--file=<res-путь>` | Какой уровень открыть |
| `--autoplay`, `--pins=a,b,c`, `--all-at-once` | Порядок штырей |
| `--interval=<сек>` или `--interval=settle` | Паузы между штырями |
| `--jitter=<seed>` | ±1 px при появлении тел и ±15 % к паузам |
| `--mods=golden` | «Золотая лихорадка» |
| `--json` | Строка `RESULT_JSON {...}` |
| `--screen=<имя>` | Открыть экран или попап для скриншота; без окна и `--shot` — проверить и выйти |
| `--shot=путь.png@сек` | Сохранить скриншот (нужен графический режим) |
| `--smoke` | Открыть все экраны и попапы и проверить ошибки |

Примеры:

```sh
godot --headless --path . --fixed-fps 60 -- --level=f1_05 --autoplay --json
xvfb-run -a -s "-screen 0 720x1280x24" godot --path . --rendering-driver opengl3 \
  --resolution 720x1280 -- --level=f1_05 --shot=/tmp/start.png@2.5
tools/test_levels.sh
```
