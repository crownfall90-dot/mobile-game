Художественная схема всех 19 предметов: `art/act1/levels/ART_PLAN.md`. Фоны пока не нарисованы. Opus сопоставляет темы 12–19 с уровнями; реализация головоломок остаётся у него.

Проверено для комнаты: PNG импортированы в Godot и открыт предварительный кадр 450×1000. Размеры слоёв соответствуют брифу. Окно заметно не совпадает с проёмом; это текущий визуальный дефект черновика. Проверки на телефоне не было. Следующий художественный шаг — подогнать окно и создать фон кухни с её отдельными предметами.
