Статусы: `new`, `needs-info`, `investigate`, `planned`, `duplicate`, `fixed`, `not-planned`, `info` (каждый с префиксом `triage:`). Типы: `bug`, `crash`, `improvement`, `ux`, `performance` (префикс `type:`). `investigate` означает проверку, а не доказанный crash. `planned` для предложения ставится **только после явного решения владельца** и с ID задачи Vita. `fixed` требует версии исправления; если исправление есть лишь в исходниках, так и указать, не объявляя его доступным в APK. `duplicate` требует ссылку на основной источник и обоснование общей причины; сходного заголовка недостаточно. Для ошибок без подтверждения — `needs-info`; для подтверждённых кодом, логом или воспроизведением — `investigate` и затем отдельная задача, если её ещё нет. В ROADMAP переносить только принятые предложения, подтверждённые проблемы и существенный долг стабильности; сырой отзыв не переносить.
