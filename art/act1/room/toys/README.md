Промпты встроенного инструмента:

1. Пять полных отдельных игрушечных кубиков в одном горизонтальном ряду,
   равные ячейки и промежутки, порядок blue/yellow/red/green with yellow star/cream.
   Геометрия, камера 45°, простые тёплые контуры и оттенки исходного набора;
   без наложения, пола, теней, текста и фона; настоящий прозрачный alpha.
2. Две отдельные ячейки: исходная коробка с зайкой и двумя кубиками без красного
   мяча, а справа полный изолированный красный мяч со светлым бликом. Сохранить
   тёплый мультяшный стиль, камера исходника, прозрачный фон; без лишних игрушек.
3. Точный edit исходной коробки: убрать только красный мяч и заполнить место
   коричневой внутренней стенкой. Сохранить зайку, оба кубика, ручки, углы,
   контуры, высоту передней стенки и пропорции 284:329; один предмет на alpha,
   без расширения корпуса, новых вещей, пола, теней и подписей.

Сидящие кадры уже существуют в family/actions. В runtime кубики — отдельные
Sprite2D, исходная кучка скрыта только на время игры. Мяч следует за ладонью
каждого ходьбового кадра Виты; из коробки исчезает один мяч, без дубликата.
После завершения/выхода исходные предметы восстановлены, ремонт не меняется.
Башня использует две сидящие позы: полная артикуляция руки пока не нарисована.
